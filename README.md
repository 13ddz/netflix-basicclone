# 🎬 Clone da Netflix

Projeto inspirado na interface da Netflix, desenvolvido com HTML e CSS puro.  
O objetivo foi praticar criação de layouts modernos, responsividade, organização de componentes visuais e estilização avançada.

---

## 📸 Preview

### Página Inicial
- Tela de entrada inspirada na Netflix
- Background com overlay escuro
- Navbar personalizada
- Campo de e-mail e botão de acesso

### Interface Principal
- Banner em destaque
- Seções de filmes e séries
- Cards horizontais
- Avatar e navegação estilo streaming

---

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- Flexbox
- Responsividade
- Organização de assets/imagens
